# SectionHead

The head of a dossier section: a 2px rule above, the section name in `pb-h2`, a mono status line of real counts beside it, and optional tools pushed to the right.

- **Provide:** `<div class="pb-sectionhead">` with an `h2.pb-h2` (add `data-decode`), a `p.pb-sectionhead__status`, and an optional `.pb-sectionhead__tools`.
- **Do:** count only what is on the page. Use `pb-ph` for counts you don't have yet.
- **Don't:** write a slogan in the status line; it states facts only.

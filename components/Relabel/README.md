# Relabel

An old label blacked out with a ragged marker stroke, and a new label-maker strip stuck over it, a little lower and to the right. It says: this thing belonged to someone else, now it is mine.

- **Provide:** `<span class="pb-relabel">` with `<span class="pb-redact" style="--len:10" aria-hidden="true">` (length in characters) and a `.pb-dymo` with the new name.
- **Do:** use it once or twice per page: on About beside my name, or on a section head.
- **Don't:** write any old text under the marker. There is no previous owner's text, only the black stroke.

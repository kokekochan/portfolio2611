# Dymo

A label-maker strip: raised uppercase mono letters on signal tape, cut with notched ends, each letter a pixel off its line, the whole strip a little crooked.

- **Provide:** `<span class="pb-dymo">Fig. 01</span>`. `PB.init()` splits it into letters (screen readers read the whole word). `--pb-dymo-tilt` sets the lean (default −1.2°).
- **Do:** use it to name things that were relabelled: a Fig. number on a rebuilt case, a section name stuck on a window, a new label over a blacked-out old one (`Relabel`). My name goes on a strip once per page at most, in `Relabel`. One to three words.
- **Don't:** use it for sentences or more than three times per screen height.
